# 开通会员页静态预览

这是一个可直接部署到 GitHub Pages 的静态页面。

## 文件

- `index.html`：页面入口
- `styles.css`：响应式缩放和动画覆盖位置
- `assets/page-reference.png`：完整页面静态参考底图
- `assets/vip-animation.webm`：顶部 VIP 动画
- `assets/page-base.png`、`assets/privileges.png`：备用切图素材

## GitHub Pages

1. 把 `vip-member-page` 目录提交到 GitHub 仓库。
2. 在仓库 `Settings -> Pages` 中选择要发布的分支。
3. 如果仓库只放这个页面，可以把本目录内容放在仓库根目录。
4. 如果保留在 `vip-member-page` 子目录，可在 Pages 中选择对应目录，或开启 GitHub Actions 部署。
